# 多参数测控系统｜STC15 / 8051

基于 IAP15F2K61S2 竞赛开发板的多参数测控原型，独立于蓝桥杯备赛作品集。整合温度、电压、频率采集，超声波测距显示、时钟记录、报警、参数掉电保存及串口配置。

## 实现功能

- DS18B20 温度采集与 CRC 校验；PCF8591 电压采集、频率分段 DAC 输出。
- NE555 经 P3.4/T0 输入脉冲，200ms 窗口测频，处理计数溢出与校准无效值。
- T1 提供 1ms 系统节拍，调度按键、数码管与 LED；主循环分时处理采集与业务。
- DS1302 时钟读取、设置，记录最新一次新增报警类别与时刻。报警记录位于 RAM，不承诺掉电保留。
- PCA 捕获超声波回波，距离仅用于显示，不参与报警。
- UART1 使用 9600bps、8N1：中断收发字节，主循环解析查询和参数配置命令。
- 温度、电压、频率阈值报警，温控继电器回差控制与蜂鸣器消音。
- AT24C02 保存阈值与频率校准参数，写入后读回校验。

## 硬件资源

| 资源 | 用途 |
| --- | --- |
| T0 / P3.4 | NE555 外部脉冲计数 |
| T1 | 1ms 系统节拍 |
| T2 | UART1 波特率发生器 |
| PCA / CCP0 / P1.1 | 超声波回波下降沿捕获 |
| P1.0 | 超声波发射 |
| P1.4 | DS18B20 单总线 |
| UART1 / P3.0、P3.1 | 串口查询、配置与上报 |

实板芯片为 IAP15F2K61S2，时钟 12MHz；代码沿用同系列 STC15F2K60S2.H 寄存器头文件。超声波接口沿用竞赛板的脉冲发射和接收电路，不是 HC-SR04 高脉宽接口。DAC 与继电器为独立输出路径。

## 构建与运行

安装 Keil C51，并配置 STC 寄存器头文件。打开 User/Measure.uvproj 查看工程，或修改 build.ps1 中的工具链目录后运行脚本。默认目录为 C:/Keil_v5/C51。生成文件为 User/Objects/Xifeng.hex，通过 STC-ISP 按 12MHz 时钟烧录。

运行主机测试需要 Python 与 ziglang 包，执行 tests/run.ps1。测试直接调用共用逻辑和经机械替换中断标记的实际主程序，不代替硬件时序和精度测试。

## 面板与串口

- S4：切换温度、电压、频率、参数、距离、当前时间及报警记录页面。
- S5：选择参数，或切换报警记录类别与时间。
- S8/S9：增减参数；S12：保存；S13：消音或取消消音。
- 串口命令以回车或换行结束，区分大小写。例如 `GET`、`PAR`、`LOG`、`T=35`、`V=300`、`F=2000`、`C=-100`、`SAVE`。
- 查询当前时间：发送 `TIME?`，末尾为英文半角问号，是命令的一部分；设置时间：发送 `TIME=13:05:09`。
- 电压参数 `V=300` 表示 3.00V；参数修改立即生效，`SAVE` 后才掉电保存。
